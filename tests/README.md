# tests/

Тест-кейсы воркфлоу. На каждый воркфлоу папка `tests/<имя>/`, внутри пары файлов:

- `case-NN.input.json` — входные данные, как их получит триггер (тело вебхука, элемент расписания и т. п.)
- `case-NN.expected.json` — ожидаемый выход воркфлоу
- `input.schema.json` — JSON Schema входа, если контракт нетривиальный (на него ссылается Requirement «Input contract»)

Правило: один Scenario в спеке = минимум один кейс здесь. Прогон делается тестовым воркфлоу в n8n
(нода Execute Workflow с данными из case-NN.input.json) или через pin data в редакторе.

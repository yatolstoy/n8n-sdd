# workflows/

Экспорт воркфлоу из n8n, по одному файлу на воркфлоу. Имя файла = имя воркфлоу в n8n = имя спеки в `openspec/specs/`.

Файлы здесь не редактируются руками. Цикл: изменить в n8n (dev) → `npm run export -- <имя>` → коммит вместе со спекой.
Скрипт нормализации убирает изменчивые поля (даты, versionId, pinData), сортирует узлы по имени и сбрасывает `active` в false.
